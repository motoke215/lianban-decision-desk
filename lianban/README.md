# 连板决策台 · Windows 桌面版 + 安卓版

把原来跑在 muse 云端的「连板决策台」做成**不需要服务器**的本地应用：

- **Windows**：安装包（exe），数据存在 `%APPDATA%\连板决策台\lianban.db`
- **安卓**：APK，数据存在应用私有目录
- 原版的全部功能都在：今日决策、仓位计算、异动、回测、交易日志、复盘、小黑板、大钱流向
- 决策规则（红灯否决、五项评分、周期阶段、仓位熔断）和原版是**同一份代码**，没有改写
- 新增：行情采集自带（涨停池、五档行情、盘中事件）、小黑板和大钱流向自动抓取、一键用采集器数据填充当日市场数据

## 一、怎么得到安装包（不需要装任何开发环境）

1. 在 GitHub 新建一个**私有**仓库，把本目录全部文件上传（或 `git push`）。
2. 打开仓库的 **Actions** 页 → 选「打包 Windows 安装包与安卓 APK」→ **Run workflow**。
3. 约 10 分钟后，运行记录底部的 **Artifacts** 里有两个文件：
   - `连板决策台-Windows安装包` → 里面是 `LianbanDecisionDesk-Setup-1.0.0.exe`
   - `连板决策台-安卓APK` → 里面是 `app-release.apk`
4. Windows：双击安装。安卓：把 APK 传到手机，允许「安装未知来源应用」后安装。

> 安卓签名密钥放在 `build/lianban-release.keystore`（密码 `lianban123456`），已经固定。**请保留这个文件**：以后每次打出的 APK 签名一致，才能直接覆盖升级而不丢数据。仓库请保持私有。

## 二、第一次使用

- 首次启动会自动带入云端导出的 2 个交易日数据（10-23、10-26）。
- 交易时段（交易日历为准：9:15–11:35、12:55–15:05）应用会自动在后台采集；设置页（「仓位」标签最下方）有「行情采集」面板，可看状态、手动「立即刷新一次」、看运行日志。
- 收盘后会自动补一轮收盘快照；15:10 后抓板块大钱流向；盘后包发布后（约 17:00 起）补小黑板，缺哪天补哪天（回看 7 天）。
- 「今日决策」里录入市场数据时，点 **「用采集器数据自动填充」**：涨停/跌停家数、最高连板、炸板率、封板率、昨涨溢价、连板晋级率、主流题材一次填好，核对后保存。盘中抓到的数据会提示「收盘后再填更准」。
- **手机端需要应用保持在前台才会持续采集**（安卓会冻结后台应用）；电脑版开着就行。

## 三、手机和电脑之间同步

数据只存在各自设备上。同步方法：一端「仓位」标签最下方 **导出备份** → 另一端 **导入备份**（会覆盖本机数据）。备份文件和云端的 `space-data.json` 同格式，互相可导入。建议定期导出一份留底。

## 四、和原版的差异（请知悉）

| 项目 | 原云端版 | 本地版 |
|---|---|---|
| 东财池子 | 经自建 Cloudflare 桥转发（云端电脑出口被东财拒绝） | **国内网络直连**，不再需要桥；被限流（403）时自动冷却 30 分钟，并用最近快照降级运行 |
| 腾讯备用源 | 云端电脑不可达 | 保留为新浪失败时的热备，国内应可用 |
| 新浪板块资金流备用源 | 有（成分树 705 个概念节点，低频抓取） | **未移植**（东财直连主源为准；主源失败时当日缺档如实显示） |
| 采集进程 | 常驻后台，全天 | 应用开着时采集；手机仅前台 |
| 数据位置 | 云端 SQLite | 本机 SQLite 文件 |
| 通达信日线对账 `tdx_recon.py` / 收盘对账 `recon_job.py` | 有 | **未移植**（决策台里已有的对账记录保留，可查看） |

## 五、开发（可选）

```
npm install
npm run typecheck        # 类型检查
npm run test:runtime     # 用真实导出数据跑一遍服务端逻辑
npx vitest run           # 采集器 / 调度器 / 界面冒烟测试
npm run dev              # 浏览器调试（只能看界面，行情因跨域拉不到）
npm run electron:build   # 本机打 Windows 安装包（需 Windows）
npm run android:sync     # 把网页同步进 android/，再用 Android Studio 打开 android/ 编译
```

目录：`src/` 前端（原 App.tsx 基本未改）· `server/` 原 actions/schema（未改）· `runtime/` 本地运行时（替代云平台 SDK）· `collector/` 采集器（TypeScript 移植）· `electron/` Windows 壳 · `android/` 安卓壳 · `seed.json` 内置数据。

来源与致谢见 `NOTICE.md`。
